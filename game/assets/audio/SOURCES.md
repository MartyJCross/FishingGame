# Audio sources

Every file here is CC0 1.0 or US public domain, checked on the file's own page (Freesound sound page licence box = "Creative Commons 0"; Wikimedia Commons file page = Public domain; OpenGameArt page licence = CC0). Freesound files are the public HQ preview MP3 of the CC0 sound. Commons .ogg/.oga originals were taken as Commons' own MP3 transcode. Durations measured from the files in this folder. Field recordings do not loop sample-perfectly: give ambience loops a short crossfade.

Format: path | title | author | source page | licence | seconds | description
